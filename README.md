# sticky-store

Catalog for the Sticky app's Apps tab. The Sticky app reads this repo and installs apps on the stick.

```
index.json          signed catalog
keys/release.pub    release public key, pinned in the app
apps/<id>/          source of one app
looks/<id>/         source of one look
dist/<id>-<ver>.app published packages
```

`index.json` and `dist/` are generated by the publisher's tools; don't edit them by hand.

The app reads the tag `v<its own version>` (for example `v0.8.20`) and uses the copy bundled in the app when the tag doesn't exist.
